# REEDS fixes — 2026-09-10

## Problems fixed

1. **Version spam (tuple/list signature bug)**  
   `prediction_signature` was stored as a Python `tuple` in a JSON column. On read it became a `list`, so every refresh looked "changed" and created a new version + timeline noise.  
   **Fix:** signature is now a JSON-safe `list`; comparison normalizes legacy shapes.

2. **Cold-start / neutral-prior cards shown as Early reads**  
   Form 1.2/1.2, Elo 1125-1125, projected 2.45 were leaking to the intelligence page.  
   **Fix:** hardened `_default_driven`, stamp `cold_start` / `data_depth` / `history_count_*` from features → ensemble → quality gate → AI-reads filter. Customer page returns `status: "insufficient_data"` instead of a wall of prior cards.

3. **League string mismatch (`soccerChampionship` → default 0.75)**  
   **Fix:** `_normalize_league_key` maps provider noise onto `SOCCER_LEAGUE_DIFFICULTY` (Championship → 0.85, etc.).

4. **Team identity split (`West Ham United FC`, `Wrexham AFC`)**  
   **Fix:** expanded alias map + strip trailing FC/AFC/CF suffixes before lookup.

5. **`edge_score` was confidence, not edge**  
   **Fix:** 1X2 / Double Chance edge is model_prob − implied when odds exist; otherwise 0 (never pretend confidence is edge). Cold-start confidence scaled down.

6. **Frontend**  
   Handles `insufficient_data` status with a clear message instead of empty/spam cards. Thin-data pill on cards.
